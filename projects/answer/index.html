Reaction API authorization bypass for restricted content

CVE-2026-90910 [CVE] [CVE json] [OSV json]

Last updated: 2026-10-19T09:35:53.657Z

Affected

  • Apache Answer through 2.0.2

Description

Missing authentication for critical function vulnerability in Apache Answer.

This issue affects Apache Answer: through 2.0.2.

The reaction API did not enforce content visibility controls, allowing unauthorized users to read reaction metadata from restricted content or add and remove their own reactions.

Users are recommended to upgrade to version 2.0.3, which fixes the issue.

Incorrect permission mapping allows users with only the unpin permission to hide/show questions

CVE-2026-64945 [CVE] [CVE json] [OSV json]

Last updated: 2026-10-19T09:30:50.536Z

Affected

  • Apache Answer through 2.0.2

Description

A vulnerability in Apache Answer.

This issue affects Apache Answer: through 2.0.2.

The question operation controller gates hide/show operations on the wrong permission check result (the unpin permission instead of the hide permission), so in custom role configurations that separate these permissions, a user granted only question.unpin can hide or restore questions without holding question.hide or question.show.

Users are recommended to upgrade to version 2.0.3, which fixes the issue.

Stored XSS via unsanitized HTML in imported question content

CVE-2026-64944 [CVE] [CVE json] [OSV json]

Last updated: 2026-10-19T09:26:51.147Z

Affected

  • Apache Answer through 2.0.2

Description

Improper Neutralization of Input During Web Page Generation ('Cross-site Scripting') vulnerability in Apache Answer.

This issue affects Apache Answer: through 2.0.2.

The importer stores imported question bodies as raw HTML without passing them through the normal Markdown-to-HTML sanitization path, so attacker-controlled HTML embedded in an imported data source is persisted and rendered to all viewers (including privileged users) as stored XSS.

Users are recommended to upgrade to version 2.0.3, which fixes the issue.
