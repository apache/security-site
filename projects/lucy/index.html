stack-buffer-overflow in JSON parser error reporter on malformed input

CVE-2026-61486 [CVE] [CVE json] [OSV json]

Last updated: 2026-08-05T06:44:06.722Z

Affected

  • Apache Lucy through *

Description

** UNSUPPORTED WHEN ASSIGNED ** Stack-based Buffer Overflow vulnerability in Apache Lucy.

This issue affects Apache Lucy: all versions.

As this project is retired, we do not plan to release a version that fixes this issue. Users are recommended to find an alternative or restrict access to the instance to trusted users.

NOTE: This vulnerability only affects products that are no longer supported by the maintainer.
