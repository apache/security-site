REST API is unauthenticated

CVE-2026-128841 [CVE] [CVE json] [OSV json]

Last updated: 2026-11-16T09:03:38.838Z

Affected

  • Apache Griffin Web Service through *

Description

** UNSUPPORTED WHEN ASSIGNED ** Missing authentication for critical function vulnerability in Apache Griffin Web Service. The REST API does not have any authentication. This includes sensitive endpoints, such as job submission when a Livy/Spark backend is configured. The API must be properly secured on the network level, and this fact was arguably not documented as clearly as it could have.

This issue affects Apache Griffin Web Service: all versions.

As this project is retired, we do not plan to release a version that fixes this issue. Users are recommended to find an alternative or restrict access to the instance to trusted users.

NOTE: This vulnerability only affects products that are no longer supported by the maintainer.

SQL Injection Vulnerability in Hive Metastore Module

CVE-2026-52691 [CVE] [CVE json] [OSV json]

Last updated: 2026-09-04T13:39:09.136Z

Affected

  • Apache Griffin Hive Metastore Module through *

Description

** UNSUPPORTED WHEN ASSIGNED ** Improper Neutralization of Special Elements used in an SQL Command ('SQL Injection') vulnerability in Apache Griffin Hive Metastore Module. 

This issue affects Apache Griffin Hive Metastore Module: all versions.

As this project is retired, we do not plan to release a version that fixes this issue. Users are recommended to find an alternative or restrict access to the instance to trusted users.

NOTE: This vulnerability only affects products that are no longer supported by the maintainer.
