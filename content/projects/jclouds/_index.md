## XML External Entity (XXE) in provider-response parsing ## { #CVE-2026-119724 }

CVE-2026-119724 [\[CVE\]](https://cve.org/CVERecord?id=CVE-2026-119724) [\[CVE json\]](./CVE-2026-119724.cve.json) [\[OSV json\]](./CVE-2026-119724.osv.json)



_Last updated: 2026-11-03T09:38:48.198Z_

### Affected

* Apache JClouds before *


### Description

<p>** UNSUPPORTED WHEN ASSIGNED ** Improper restriction of recursive entity references in DTDs ('XML entity expansion') vulnerability in Apache JClouds.</p><p>This issue affects Apache JClouds: all versions.</p><p>As this project is retired, we do not plan to release a version that fixes this issue. Users are recommended to find an alternative or restrict access to the instance to trusted users.</p><p>NOTE: This vulnerability only affects products that are no longer supported by the maintainer.</p>
