## SQL Injection Vulnerability in Hive Metastore Module ## { #CVE-2026-52691 }

CVE-2026-52691 [\[CVE\]](https://cve.org/CVERecord?id=CVE-2026-52691) [\[CVE json\]](./CVE-2026-52691.cve.json) [\[OSV json\]](./CVE-2026-52691.osv.json)



_Last updated: 2026-09-04T13:39:09.136Z_

### Affected

* Apache Griffin Hive Metastore Module through *


### Description

<p>** UNSUPPORTED WHEN ASSIGNED ** Improper Neutralization of Special Elements used in an SQL Command ('SQL Injection') vulnerability in Apache Griffin Hive Metastore Module.&nbsp;</p><p>This issue affects Apache Griffin Hive Metastore Module: all versions.</p><p>As this project is retired, we do not plan to release a version that fixes this issue. Users are recommended to find an alternative or restrict access to the instance to trusted users.</p><p>NOTE: This vulnerability only affects products that are no longer supported by the maintainer.</p>
